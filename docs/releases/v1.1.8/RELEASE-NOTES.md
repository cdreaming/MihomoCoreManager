# Mihomo Core Manager v1.1.8

v1.1.8 以 v1.1.7 为基线，保留已验证的异步按钮 busy 动画与任务完成检测，集中修复通知、侧栏命中区域和设置页首次打开问题。

## 改进

- **操作完成通知自动收起**：成功提示不再永久停留。若提示由异步按钮操作产生，会等该按钮真正退出 busy 状态后再启动自动收起计时；错误提示仍保留，便于查看。
- **侧栏点击区域扩大**：概览 / Core 控制 / 订阅管理 / 运行日志 / 设置的整行区域均可点击，原生行高提升到 47pt，并增加明显的按下缩放、下沉、亮度和回弹反馈。portable Web UI 同步扩大到 46px。
- **设置页首次打开修复**：修复持久化页面下 `task(id:)` 使用了被转义的插值字符串，导致应用启动时任务提前返回、首次切换到“设置”不再触发加载的问题。现在首次进入设置即可直接显示默认服务器的完整选项。
- **运行日志同步修复**：同类 `task(id:)` 插值问题一并修复，首次进入运行日志时也能按当前服务器正常加载。
- **v1.1.7 动画完整保留**：当前操作按钮仍保持 spinner / busy cursor，项目升级仍会一直等待远端任务真正结束。

## 版本

App v1.1.8 (build 118)，Mihomo Core 管理面板 API 兼容基线 v4.0.0。
