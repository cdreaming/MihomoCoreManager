# v1.2.5 QA

## 状态栏代理选择

1. 打开状态栏菜单，记录任意代理组当前后缀 `组名 · A`。
2. 进入该组并改选线路 `B`；无需关闭菜单，顶层代理组后缀应立即变为 `组名 · B`。
3. 若 `B` 本身是另一个代理组，后缀也应立即显示该代理组名称。
4. 重新打开子菜单，新的当前项应有勾选状态，旧项不应继续勾选。
5. 模拟 Controller PUT 成功后首次 GET 暂时返回旧 `now`：界面和菜单不应跳回旧线路；后续权威状态收敛后仍正常刷新。

## 主窗口

1. 主窗口顶部不应再出现独立标题栏色块或 `Mihomo Core 管理面板` 居中标题。
2. 左侧导航从窗口顶部贯穿到底部，右侧页面同时从窗口顶部开始，形成完整左右两栏布局。
3. macOS 原生红/黄/绿窗口按钮应仍可用；窗口顶部空白区域应仍可拖动窗口。
4. 左侧标题区应显示蓝紫 `M` 图标，右侧两行 `Mihomo Core` / `管理面板` 使用与界面一致的系统字体和主文字色（深色界面呈柔和白色），下方显示 Core、面板、MetaCubeXD 三行版本。
5. 侧栏不应再出现第二个重复的独立 `Mihomo Core` 大标题。
6. 1180×760 默认窗口下，标题、导航及“管理后端”均不应被截断；窗口缩窄时仍应保持可用。

## 回归

- 状态栏下拉菜单上传/下载速度保持单行。
- 代理组区域前后分隔线仍存在。
- 代理测速、默认顺序、provider-only 节点与嵌套代理组延时保持 v1.2.4 行为。
- Core 启停/重启、订阅保存、运行日志、项目升级和后端服务器切换保持可用。
