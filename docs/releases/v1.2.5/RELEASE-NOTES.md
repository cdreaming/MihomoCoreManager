# Mihomo Core Manager v1.2.5

v1.2.5 以 v1.2.4 为稳定基线，继续收紧状态栏交互和主窗口视觉层级。本次修订重点解决代理组切换后状态栏后缀不及时刷新，并把主窗口改造成无独立标题栏的完整左右布局。

## 状态栏下拉菜单

- 上传/下载实时网速保持单行菜单项：`↑ 上传 …   ↓ 下载 …`。
- 代理组区域在前后使用分隔线，作为独立视觉分组，与 Core 控制及管理工具分离。
- 修复从状态栏重新选择线路/代理组后，顶层代理组后缀仍显示旧线路的问题。
- portable 在 Controller PUT 成功后立即更新本地 `proxies.json` 菜单快照、提高 generation，并直接刷新仍在屏幕上的 `组名 · 当前线路/代理组` 根菜单标题；随后再延迟拉取一次权威状态。
- 原生 SwiftUI 在选择成功后先保留已确认的本地 `now`，即使紧接着的 Controller GET 短暂返回旧值也不会把菜单后缀跳回；`Menu` identity 同时包含当前选中项，强制刷新标签和勾选状态。

## 主窗口布局与标题区

- 主窗口改为完整的**左侧导航 + 右侧内容**两栏布局，内容直接延伸到窗口顶部，不再绘制单独的视觉标题栏。
- portable 删除原 36px HTML titlebar；仅保留顶部 22px 不可见原生拖拽区域，维持 macOS 窗口拖动体验。
- 原生 SwiftUI 继续使用 `hiddenTitleBar + fullSizeContentView`，不绘制标题底板；保留 macOS 原生关闭/最小化/缩放按钮。
- 左栏宽度统一为 256pt/px，标题区按参考样式重排为：蓝紫渐变 `M` 图标 + 右侧两行金色 `Mihomo Core / 管理面板`，版本信息置于其下。
- 移除侧栏中重复的独立 `Mihomo Core` 大标题；字体层级、字重、间距和颜色与 Dashboard 深色体系统一。
- 深色侧栏使用更完整的不透明中性背景，品牌标题使用与主界面一致的柔和白色文字，导航仍沿用系统蓝强调色。

## 代理页同步

- portable 代理页同样把刚确认成功的选择视为当前组的权威状态；后续首次 GET 即使短暂返回旧 `now`，也不会在界面上回退到旧线路。

## 兼容性

- 保留 v1.2.4 的 Cloudflare 530 / Error 1033 容错、代理快照、provider-only 节点合并、嵌套策略组解析、测速与线路切换异步队列。
- 状态栏本体继续保持上传/下载双行速度布局；“单行”仅指状态栏**下拉菜单**中的速度项。
