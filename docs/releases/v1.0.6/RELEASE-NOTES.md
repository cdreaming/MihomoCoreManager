# Mihomo Core Manager v1.0.6

v1.0.6 继续兼容 **Mihomo Core 管理面板 v4.0.0**。本次只做实际使用反馈驱动的状态栏与侧栏 UI 优化，不改变远端 API 语义。

## 状态栏网速

- 网速改为紧凑双行显示，参考常见 macOS 菜单栏网速工具。
- 第一行：`↓ Download`；第二行：`↑ Upload`。
- 数字使用紧凑单位与等宽数字，减少菜单栏占宽。
- Running / Stopped / Offline 保持单行状态，与两行速度横向分开。
- portable 即时安装版移除 CATextLayer 文字渲染，改用 `NSStatusBarButton` 原生多行标题，避免缩放、裁切和垂直对齐差异。
- 状态快照过期恢复与下拉菜单实时上传/下载值继续保留。

## 左侧管理后端

- 删除品牌信息区下方原来的大尺寸后端选择卡片。
- “管理后端”移动到“设置”正下方，字号、行高、文字权重和交互与其它侧栏菜单统一。
- 去掉触发器中的紫蓝 M 方块图标。
- 后端下拉列表同样移除重复 M 方块，使用服务器名称、Endpoint、Secret 警示与选中勾的轻量布局。
- “服务器设置…”入口继续保留。

## 保留

- 标准 macOS 窗口拖动。
- 设置 Tab。
- Core Secret `⌘V` 与显式“粘贴”。
- 多服务器 / 跨机管理。
- 集中状态缓存与按需页面加载。
- Developer ID 签名、公证、PKG 与 GitHub Release 自动发布链路。

版本：App v1.0.6 (build 106)，API 兼容基线 v4.0.0。
