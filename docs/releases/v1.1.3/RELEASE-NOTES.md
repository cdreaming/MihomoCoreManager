# Mihomo Core Manager v1.1.3

v1.1.3 基于 v1.1.2 的界面修复成果正式升版，版本号与构建号统一更新，同时保持已修复的界面布局不变。

## 界面状态

- 保留紧凑标题栏，减少窗口顶部无效占高。
- 保留 v1.0.9 风格的原生菜单栏标签布局。
- 保留“概览”页“实时流量 / 快速控制”的对齐修复。
- 保留“Core 控制”页“服务控制 / 服务信息”的分栏与信息行修复。
- 保留“订阅管理”页 Provider 输入区与操作区的统一排版。
- 保留“设置”页“App 与状态栏”结构化表单布局。
- 保持各页面卡片、间距、按钮和表单风格一致。

## 功能状态

- Mihomo Core 管理 API 功能保持不变。
- 管理后端选择器、多服务器 Profile、Keychain Secret、订阅保存与热重载保持不变。
- portable runtime 与 Web UI 保持不变。
- unsigned GitHub Release 流程保持不变。

版本：App v1.1.3 (build 113)，API 兼容基线 v4.0.0。
