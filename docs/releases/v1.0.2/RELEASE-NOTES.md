# Mihomo Core Manager v1.0.2

这是 v1.0.2 UI 与状态栏功能升级版，继续兼容 Mihomo Core 管理面板 v4.0.0。

## 主要更新

- 使用 Mihomo Core 管理面板同款 Dashboard UI 作为主窗口视觉基线。
- 恢复实时流量曲线以及 Memory / Upload / Download / Connections 四项实时指标。
- 状态栏可显示 `Running / Stopped` 和实时 `↑ Upload / ↓ Download`。
- 状态栏下拉菜单可分别开关运行状态、网速，或切换为仅显示图标。
- 状态栏菜单支持多服务器切换及完整 Core 管理动作。
- 保留 Core Secret `⌘V` 与显式粘贴按钮，Secret 继续存入 Keychain。

## 发布目标

- App：v1.0.2 (build 102)
- API baseline：Mihomo Core 管理面板 v4.0.0
- Platform：macOS 14.0+
- Architecture：Apple Silicon arm64 only
