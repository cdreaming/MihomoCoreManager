# Mihomo Core Manager v1.1.7

v1.1.7 聚焦异步按钮的执行反馈和项目升级状态检测。

## 按钮执行状态

- 当前被点击的异步操作按钮会持续显示旋转进度与“执行中”文案，直到对应 `async` 操作真正结束。
- AppModel 新增当前操作标识，避免所有按钮只有统一禁用状态、无法判断哪一个动作正在执行。
- 项目升级启动后持续读取 `/api/project-update/log`；只有确认远端任务结束后，“开始项目升级”才恢复初始状态。
- Core 管理面板自身升级可能造成短暂断连，v1.1.7 会保持升级状态并继续等待服务恢复，而不是提前结束按钮动画。
- 设有 30 分钟保护超时，避免异常情况下界面永久停留在 busy 状态。

## 指针与点击反馈

- portable Web UI 执行期间使用系统 `cursor: progress`，按钮同时显示 spinner 与 `aria-busy=true`。
- 原生 SwiftUI 按钮显示系统 `ProgressView`，并用当前操作状态驱动动画生命周期；执行中按钮悬停时使用自定义旋转 busy cursor，“减少动态效果”开启时降级为静态忙碌指针。
- 原生按压缩放从 v1.1.6 的 `0.985` 加强为 `0.955`，同时加入轻微下沉、阴影压缩和高亮反馈。
- Web 按压缩放加强为 `0.945`，增加内阴影和快速高亮闪层；遵循 `prefers-reduced-motion`。

版本：App v1.1.7 (build 117)，API 兼容基线 v4.0.0。
