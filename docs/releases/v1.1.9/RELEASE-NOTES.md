# Mihomo Core Manager v1.1.9

v1.1.9 以 v1.1.8 为稳定基线，本版重点优化 macOS 状态栏。

## 改进

- 状态栏显示改为左侧应用图标、右侧上传/下载双行数字；上传在上、下载在下。
- 网速数字使用等宽字体、固定数值列并右对齐，实时变化时排版更稳定。
- 显示运行状态且同时显示图标时，以图标右下角状态点表达 Running/Stopped，减少菜单栏宽度占用。
- 原生状态栏下拉切换为自定义紧凑面板，增加版本/运行状态、实时流量、当前服务器、Core 控制、快捷入口、项目维护和状态栏显示设置。
- 面板按钮具备按下缩放与 spring 回弹，并继续遵守现有异步 busy 生命周期。
- portable arm64 版同步修复网速顺序/对齐；原有超长菜单折叠为“服务器 / Core 控制 / 管理与工具 / 状态栏显示”子菜单并加入 SF Symbols。

## 保留

继续保留 v1.1.8 的通知自动收起、侧栏整行点击、设置/运行日志首次加载修复，以及 v1.1.7 的按钮 busy 动画与项目升级完成检测。

App v1.1.9 (build 119)，Mihomo Core 管理面板 API 兼容基线 v4.0.0。
