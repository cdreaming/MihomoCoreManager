App v__APP_VERSION__ · arm64

Mihomo Core 连接

Primary · Controller API

Controller URL 可填 API 根地址，也可直接粘贴部署结果中的 /ui/ / /Ui/ 页面地址；保存时会去掉 UI 段并保留反代前置路径。端口不会自动补；非 80/443 时请显式填写（Mihomo 常见为 9090）。Controller Secret 留空时自动兼容复用 Management Secret。Secret 支持 ⌘V，并只保存在 macOS Keychain。

mihomo.service（推荐）

systemd · SSH
mihomo.service

启动/停止优先 systemctl；重启/热重载在 Core API 失败后使用 systemctl；日志优先 journalctl -u mihomo.service。SSH 使用 BatchMode；留空时会优先从 LAN Management URL、其次从 Controller URL 自动推断服务器主机；如服务器用户名不同请显式填写 root@host。非 root 用户需预先配置免密 sudo -n。Controller/Management 端口直连失败时，还会通过 SSH 从服务器本机访问原端口（必要时改试 127.0.0.1）。失败时自动回退 Core 服务面板。

扩展管理（可选）

Core 服务面板 · Fallback

Management URL 不是 Controller。它在 Core API / mihomo.service 不可用时兜底生命周期与日志，并继续承担订阅写入、配置生成、MetaCubeXD 与整套项目升级。可粘贴 /api/status 等部署结果地址，保存时自动还原面板根路径并保留反代前置路径；不会自动补 29090。
