## 流畅度与安全

- [ ] 连续打开/关闭状态栏菜单时，实时网速刷新不会让代理组区域出现明显整组闪烁、跳动或卡顿。
- [ ] 代理组只有在组顺序或成员结构真正变化时才整体重建；单纯延时/history 更新不会重建全部顶层菜单项。
- [ ] 状态栏选择线路后后缀立即更新；如果异步 PUT 失败，下一次本地快照轮询只校准该代理组，不扫描刷新所有组标题。
- [ ] 主窗口持续 1.2 秒状态轮询时，侧栏导航和代理菜单不随每次实时状态更新整树重绘。
- [ ] 打开代理页/状态栏首次加载代理时不触发全局 Busy；显式“刷新”仍保留可见 Busy 与错误提示。
- [ ] 短暂网络抖动不会让 portable 主窗口/状态栏瞬间闪 Offline；连续失败超过约 4–5 秒后旧状态会失效。
- [ ] TLS 证书验证没有关闭，Core Secret / Controller Secret 仍由原有 Keychain/鉴权路径管理；未开启 `Allow Insecure HTTP` 时仍拒绝明文 HTTP。
- [ ] GET/HEAD 可做有上限的临时错误重试；POST/PUT 等写操作不自动重试，避免重复执行副作用。
- [ ] `go test -race ./...` 通过，未发现 portable 状态/代理缓存并发数据竞争。
