# Mihomo Core Manager v1.1.9 QA

## 状态栏

- [ ] 默认开启图标 + 状态 + 网速时，应用图标位于最左侧。
- [ ] 上传速率在第一行、下载速率在第二行。
- [ ] 两行速率数值右对齐，B/s、KB/s、MB/s 切换时不明显左右跳动。
- [ ] 关闭网速后 Running/Stopped 状态仍可辨识。
- [ ] “仅显示图标”后状态栏仍可点击恢复设置。

## 下拉面板

- [ ] 原生菜单点击后显示紧凑自定义面板，而非旧版超长标准菜单。
- [ ] Core 启停、重启、重载、应用订阅按钮禁用状态正确，执行中 busy 状态持续到任务结束。
- [ ] 服务器切换、主窗口、订阅管理、运行日志、项目升级、MetaCubeXD、设置均可正常打开。
- [ ] 检查项目更新、开始项目升级动作可用。
- [ ] 状态栏“图标 / 状态 / 网速 / 仅图标”设置立即生效并持久化。

## portable

- [ ] Apple Silicon portable 状态栏显示上传在上、下载在下，文字列右对齐。
- [ ] portable 下拉菜单使用分组子菜单，避免旧版纵向菜单占满屏幕。
- [ ] portable recovery shell 仍可在 JXA 菜单失败时启动。
